# Predictive Modeling and Risk Scoring for Bank Customer Churn
Project Overview

This project focuses on predicting bank customer churn using machine learning techniques. It identifies customers who are likely to leave the bank and assigns a churn probability score to help banks take proactive retention measures.

Objectives

Predict whether a customer is likely to leave the bank.

Generate probability-based churn risk scores.

Identify key factors influencing customer churn.

Evaluate machine learning models using classification metrics.

Support data-driven customer retention strategies.
